## Acceptance criteria (each room individually)
1. Inventory every installed *visible* prop, source/license, human-scale measured oriented bounds, floor/support/contact, intended function, front direction, and owning room. Assign KEEP, REORIENT, REPLACE, REMOVE or REHOME. No approval based on filename or count. For the inherited sci-fi counter, graveyard-kit bench, display podium, generic racks, and older arcade machines: photograph/audition at eye level and compare to actual intended role. Retain only if visually defensible. Never restore Cassette banned shelves; no procedural substitute for missing licensed primary fixture.
2. Design customer/employee circulation before adding merch. Primary routes target ≥2 m unobstructed where geometry allows, secondary browsing ≥1.2 m, queue approach ≥1.2 m. Existing 4.2m thresholds, cabinet hiding, E targets, panel and key paths preserved. Measure actual footprint and use-space (chairs pull out, arcade player stands/seats, shelves approachable). Collision and visible geometry share source coordinates.
3. Full-scale floor furniture uses one uniform scale, actual bounding box floor contact, no squeeze to fit. Actual tabletop/shelf support measured at contact location, not a guessed Y or blindly highest mesh vertex. Reject toy-scale, upside-down, modern anachronism, inappropriate shape; verify intended front on actual mesh. Prioritize authentic local CC0 models or original printed packaging where appropriate; no unlicensed assets, no off-origin runtime loads.
4. Treat empty room zones as meaningful (queue, clear path, shop windows, clearance, stock work, deliberate abandoned area), not leftover space. Rows/aisles coherent, each store identity visible from entrance. Plan fixture groups and stock families rather than distributing arbitrary props on a grid. Visual evidence: entrance, checkout, back, shelf closeup, and surveyed overhead actual shared V111 assembly, plus real game eye-level chapter interaction clearance.
5. Render at normal after-hours lighting and brighter audit illumination. Lighting must communicate purposeful zones without flattening horror. Preserve floor/ceiling/door geometry, existing darkness pacing and canon. Each batch must pass source + original desktop; update this document with actual screenshots/measurements and remaining defects. No merge based on source tests alone.
